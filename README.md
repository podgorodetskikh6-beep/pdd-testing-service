# Сервис для прохождения тестов по ПДД

Приложение для прохождения тестирования по правилам дорожного движения.

Проект разработан на Python с использованием принципов объектно-ориентированного программирования, многослойной архитектуры и базы данных SQLite.

## О проекте

Сервис позволяет пользователю выбирать билет, проходить тестирование по правилам дорожного движения и просматривать статистику по результатам тестирования.

Проект разработан с разделением ответственности между отдельными слоями: моделью данных, работой с базой данных билетов, бизнес-логикой и пользовательским интерфейсом.

## Основная функциональность

- регистрация;
- выбор билета для прохождения теста;
- прохождение тестирования по ПДД;
- отображение вариантов ответов и изображений;
- автоматическая проверка ответов;
- завершение теста в соответствии с результатами;
- сохранение результатов тестирования;
- просмотр статистики.

## Архитектура проекта

Проект построен по многослойному принципу:
UI (Пользовательский интерфейс) &rarr; Core (Бизнес-логика) &rarr; Repository (Слой доступа к данным )&rarr; SQLite (База данных вопросов)

## Основные компоненты

model.py
Модели данных приложения: пользователь, вопрос, билет и статистика.

repository/
Слой взаимодействия с базой данных SQLite. Отвечает за хранение и получение данных.

core/
Бизнес-логика приложения: работа с пользователем, проведение тестирования и обработка статистики.

ui.py
Пользовательский интерфейс приложения, реализованный с помощью Tkinter.

main.py
Точка входа в приложение и связывание основных компонентов системы.

pdd.db
SQLite-база данных с билетами, вопросами, вариантами ответов, пользователями и результатами тестирования.

images/
Изображения, используемые в вопросах.  

## ООП
При разработке использовались основные принципы объектно-ориентированного программирования:
классы и объекты;
инкапсуляция;
наследование.

## База данных

Для хранения данных используется SQLite. База содержит информацию о:
пользователях;
билетах;
вопросах;
вариантах ответов;
результатах прохождения тестов.

Взаимодействие с базой данных вынесено в отдельный слой repository, поэтому бизнес-логика приложения не работает с SQL напрямую.

## Cтатистика
После прохождения тестов результаты сохраняются в базе данных. Приложение позволяет анализировать результаты пользователя и отображать статистику прохождения тестов, включая визуализацию данных через графики.

## Запуск проекта
1. Клонирование репозитория
```text
git clone https://github.com/podgorodetskikh6-beep/pdd-testing-service.git
```
2. Переход в директорию проекта
```text
cd pdd-testing-service
```
3. Создание виртуального окружения.
```text
python -m venv .venv
```
4. Активация виртуального окружения

macOS / Linux:
```text
source .venv/bin/activate
```
Windows:
```text
.venv\Scripts\activate
```
5. Установка зависимостей
```text
pip install -r requirements.txt
```
6. Запуск приложения
```text
python main.py
```
